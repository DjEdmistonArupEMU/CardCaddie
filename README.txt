CardCaddie PWA

This folder is the installable web-app version.

IMPORTANT: a PWA requires these files to be served together from an HTTPS website. Opening index.html directly from the Files app (file://) does not install the service worker and therefore is not a proper Home Screen app.

Publish the contents of this ZIP to any static HTTPS host (for example GitHub Pages, Cloudflare Pages, Netlify, or your own web server), then open that URL on the phone.

iPhone/iPad: Safari > Share > Add to Home Screen > Open as Web App > Add.
Android: Chrome > menu > Add to Home screen / Install app.
